# 🔨 わくわく家具工房

MakeRoom の家具づくりにインスパイアされた、Three.js 製の家具組み立てシミュレーターです。
板・脚・箱などのパーツを、プラモデルやジオラマのように組み合わせて家具を作れます。

- **外部の3Dアセットは使っていません。** 形はすべて Three.js のプリミティブ／押し出し形状、
  木目・チェック・ドット・カッティングマット・床・壁紙の模様は canvas でコードから生成しています。
  （リポジトリ内の `.glb` ファイルは読み込んでいません）

## あそびかた

`index.html` をブラウザで開くだけで動きます（ES Modules を使うので、ローカルでは簡単なサーバー経由がおすすめです）。

```sh
npx serve .   # または python3 -m http.server
```

### 🛠️ じゆう工作
- 左のパレットからパーツを選び、作業台（カッティングマット）をクリックして置く
- パーツの上・横の面にくっつく（表面スナップ）／マス目スナップ
- `Shift+クリック` で続けて置く、置く前に `R` でまわす・`T` でたおす
- 置いたパーツを選んで 移動 `1` ／ 回転 `2` ／ サイズ `3`（のばす・ちぢめる）
- 左右・上下反転、「下にくっつける」、複製 `D`、削除 `Delete`、元に戻す `Ctrl+Z`
- 色 24色＋自由色、しあげ（木目・マット・つやつや・メタル・チェック・ドット・ガラス）
- 🖌️ ぬりぬりモードでクリックしたパーツをどんどん塗れる
- 💾 コレクションに保存（ブラウザの localStorage）

### 📦 組み立てキット（プラモデル風）
- 説明書のステップどおりに、ランナーからパーツを切りはなし、光っているガイド位置にはめこむ（パチッ！）
- ハートのいす／まるいテーブル／パステル本だな／ひきだしナイトテーブル／リボンランプ／ふかふかベッド
- 完成したらコレクションに保存したり、じゆう工作で色をぬって改造できる

### 🏠 お部屋ジオラマ
- 作った家具を小さなお部屋に配置（床・家具の上・壁にくっつく）
- 回転・大きさ変更・複製、床と壁紙の模様・色を変更

### 🔄 360° ビュー
- ドラッグでぐるっと360°回転（真下からも見られる）、右ドラッグで移動、ホイールでズーム
- 右下ボタン：左右に45°回転・上から・正面・うらから・くるくる回転台・ズーム・全体表示
- 📷 で写真（PNG）を保存

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面レイアウト（Three.js は CDN の importmap で読み込み） |
| `css/style.css` | パステル調のUI |
| `js/main.js` | シーン、配置・スナップ、選択・編集、キット、ジオラマ、保存 |
| `js/parts.js` | パーツ形状と材質の定義 |
| `js/kits.js` | 組み立てキットの設計図 |
| `js/textures.js` | canvas による手続き的テクスチャ |
